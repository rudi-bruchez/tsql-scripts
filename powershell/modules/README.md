# PowerShell Modules

Reusable PowerShell modules for SQL Server administration scripts.

## 📝 [sql](./sql.psm1)

Module providing `Invoke-SqlQuery` helper using `Microsoft.Data.SqlClient` (with fallback to `System.Data.SqlClient`) for robust database querying.

## 📝 [smtp](./smtp.ps1)

Function for sending HTML emails using System.Net.Mail. Used by health check and reporting scripts.

## 📝 [stylesheet](./stylesheet.ps1)

HTML stylesheet definition for formatting reports generated by the daily-check and other reporting scripts.
